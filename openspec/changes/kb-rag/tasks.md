- [x] 3.2 Implement `backend/internal/kb/indexer.go` for file-origin documents: for each candidate file, hash the raw bytes; skip the document when the hash matches the stored one and make no embedding call; on a changed hash, re-chunk and re-embed at the next generation (3.3); on a file that disappeared, delete its chunks and mark the document absent. Verify: unit tests over a temporary tree — unchanged file makes zero embedding calls (assert with a counting stub embedder), changed file replaces its chunks, deleted file's chunks are removed, an unsupported file is skipped and the rest of the tree still indexes, and every written chunk carries the embedding identity.
- [x] 3.3 Implement the two-phase write and the atomic generation swap: write the new chunks at `generation = document.generation + 1` with an empty embedding, then fill them through the claim query (`FOR UPDATE SKIP LOCKED`, scoped to that pending generation). Advance `kb_documents.generation` only once the new generation is fully embedded, then delete the superseded generation's chunks. On an embedding failure, the document SHALL end `pending` with its new chunks already stored, a later fill SHALL complete it WITHOUT re-parsing the source, and the document SHALL remain retrievable at its previous generation. Verify: unit tests — a failed embed leaves the previous chunks retrievable and the document pending; the second pass issues no parse call, completes the document, advances the generation, and removes the superseded chunks.
- [x] 3.4 Implement the inline-document branch of the indexer: read the body from `kb_documents.content` instead of a file, apply the same chunking and the same generation swap. Verify: unit test asserting the inline path produces chunks with the same shape as the file path and that an inline edit keeps the document's identity.
- [x] 3.5 Implement the explicit index trigger over the caller's visible sources (their private sources plus the shared source) and the bounded lazy catch-up — a detached context, a per-user once-guard, a bounded batch — mirroring `rag.Service.BackfillOnce`.
